# dataset_v0.2 策略修正第二组件

2026-09-13。24条原创合成候选、12对、10个场景族；策略14条、战术10条。训练侧20条、验证侧4条。两批合计56条候选，完整训练版仍未冻结，ready_for_training=false。

每对先保留玩家当时已有信息，随后只追加一条可见公开证据；验人目标出局时同步存活列表。私有事实不改写，答案描述的是当时合理决策，不使用后续胜负。公开核对记录仅确认发言/票型，不认证暗牌身份。

| 对照 | 需审核的策略变化 |
|---|---|
| vote_revision | 新增时间线证据使原质疑失效；撤回质疑不等于认证身份 |
| silver_sources | 支持来源增加但仍是玩家声称，不能升级为自己的技能事实 |
| check_plan | 区分可变未来计划和不可用计划变化解释的历史结果矛盾 |
| dark_counts | 暗牌死亡不能当作确认狼数，新增承认只推测后收紧轮次表述 |
| claim_conflict | 声称出现可定位规则矛盾后更新可信度，避免二选一假设 |
| reciprocal_votes | 团队关系判断随真实投票理由更新，不能用同票直接锁双狼 |
| seer_retarget | 新死亡证据使原目标非法，改为既定合法备选而不改写历史查验 |
| collapse_cut | 队友失信后由有限保护转为公开切割，承担历史立场和被识别风险 |
| cut_rebuttal | 狼踩狼也必须回应反证，不能为了切割强留已失效理由 |
| pressure_revision | 攻击目标根据反证改变，利用真实待解释行为而不捏造罪名 |
| ally_support | 队友身份声称变化后重新协调公开打法，当前发言阶段仍必须回应 |
| public_defense | 对手识别切割后调整辩护，承认历史而非声称切割即好人 |

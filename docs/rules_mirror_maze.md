# 镜隐迷踪：Phase 2 调研档案（暂不训练）

用户于 2026-09-10 将镜隐迷踪移出 Phase 1；规则不完整冻结，禁止混入经典训练集。

[官方赛事资料](https://langrensha.com/20240827/31012_1177119.html)确认 3 狼人、觉醒隐狼、4 平民、魔镜少女、女巫、猎人、守卫的 12 人配置。[官方发布](https://www.taptap.cn/moment/466263402654728540)确认该板子和角色。

已检索的[玩法整理](https://www.bilibili.com/opus/858231085332430870)与[角色整理](https://moegirl.icu/安托鲁斯)描述：大小狼不互认，隐狼不能自爆；一次模仿不局限首夜，身份即时得到、技能夜末后生效；模仿女巫只有毒，模仿守卫可挡毒；魔镜少女查具体身份且不能自验/重复验，隐狼模仿后显示所模仿身份。这些二手资料不足以独立认证所有边界。

后续需确认模仿目标、复制资源、接刀通知、额外刀目标、复制猎人遇毒、双盾/解药与同时胜负。现有代码的 mirror_12 路径只是可测试的扩展草案，正式数据入口必须拒绝。不要重新搜索这些已存链接来替代完成经典训练。

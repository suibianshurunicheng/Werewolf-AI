# 静态评测

classic_benchmark_v0.1：36题，包括rules12、strategy8、counterfactual8（4对）、blind8。dev用于诊断和数据修正，test保留，不能据test反馈生成训练数据。

反事实每对只改变一个可见字段，期望动作不同：三对改变技能状态，一对改变同伴首验记录是否自洽。其余输入保持一致。expected、pair_id、rubric等不进入模型Prompt。

分别报告格式正确率、合法动作率、参考动作匹配和反事实配对正确率。文本关键词仅诊断，不能当作完整推理分数；speak命中不能证明战术正确。人工rubric检查证据、保留不确定性、轮次假设、策略条件、反制和公开信息隔离。没有人工审核必须标pending。

Base与Adapter必须使用相同题目哈希、模板、生成参数、seed、量化/放置方式和token上限。逐题保存原始输出、解析失败、截断、运行指纹；恢复不重算已完成项，配置变化不得混用结果。不能只在成功题目中计算分母。

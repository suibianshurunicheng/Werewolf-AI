# 磁盘空间与迁移

用户授权：C盘空间不足时，把整个项目迁往D盘；D盘也不足时提醒租云服务器。当前没有触发迁移。

恢复以及模型下载、转录、训练、合并前检查可用空间。工作标准是预估本次新增占用后仍保留至少5GiB；不等到写满导致checkpoint损坏。记录实际容量，不把阈值当成用户声称的硬件事实。

触发时先更新PROJECT_STATUS、DECISIONS、TODO并commit；等待或暂停正在写入的训练/转录/下载，保留最近完整checkpoint。选择D:/Projects/Werewolf-AI等明确目标，先核验源和目标绝对路径；D需要容纳整个项目及余量。不能把D:/BiliDownload素材目录作为项目迁移目标。

迁移先复制完整项目（含Git、配置、数据、cache、outputs、日志），校验文件数/大小/关键SHA，再从新目录测试恢复。训练状态中的旧绝对checkpoint路径需明确重定位并记录映射，更新受影响的完整性清单；不能把改变后的文件冒充原字节哈希。确认新目录可恢复后才处理旧副本，禁止在活动cwd中盲目递归移动/删除。

执行检查：.venv/Scripts/python.exe scripts/check_disk.py --needed-gib 3 。按下一项工作的实际预估调整needed-gib。结果写入reports/disk_status.json；退出码2表示必须先处理空间，不能继续大文件工作。
D盘也不够时保存小型状态与失败说明，停止新的大文件写入，提醒用户租用至少12GB显存的云GPU或提供足够存储；不能擅自租赁或付费。12/16/24GB配置均已有模板，但对应机器容量尚未实测。

这些检查随项目执行及恢复运行，不声称在会话停止后已有独立后台磁盘监控。
